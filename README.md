Les balises sémantiques disent le rôle de chaque zone de la page (header, nav, main, footer), contrairement à une div qui est neutre. Pour l’accessibilité, les lecteurs d’écran s’en servent pour naviguer vite vers le menu ou le contenu. Pour le référencement, les moteurs de recherche comprennent mieux la structure et l’importance du contenu. Pour la maintenance, le code est plus lisible et plus facile à modifier. Elles évitent aussi d’écrire du code en plus, car certaines ont déjà un comportement prévu.
